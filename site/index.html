The problem it solves

AI inference shouldn't be a walled garden.

Every inference is expensive, every provider is a trust boundary. MeshLLM turns idle GPUs into a market, puts an escrow between buyer and seller, and keeps the data plane private end to end.

Decentralised

Permissionless mesh

Any node with a wallet and a GPU can join. Providers publish listings; consumers discover them via a content-addressed directory. No single party gates who can compute.

Encrypted

E2EE data plane

Each session builds its own AES-256-GCM key from ephemeral P-256 ECDH and wallet-bound Ed25519. The platform relays ciphertext only — it never sees your prompt or reply.

Settled

USDT escrow

FUND → IN_CALL → SETTLE_WINDOW → SETTLED. The escrow state machine holds funds before the call and settles by measured tokens. No failed calls, no trust.

The loop

Four steps. Zero trust in the middle.

A call flows through the same four beats — discovery, escrow, encrypted inference, settlement.

🌐

Discover

Consumer queries the directory for a model (e.g./listings). Listings are content-addressed and signed, so they can't be forged. The consumer picks a provider it can reach.

💵

Fund escrow

The consumer locks the expected fee + bond in the escrow state machine. State movesEMPTY → FUNDED. If the call dies, the funds are returned, not leaked.

🔐

Run E2EE

Signalling opens an encrypted data channel (direct P2P or via a relay). Prompts go to the provider's GPU; replies stream back — all ciphertext, all session-keyed.

✅

Settle

The provider submits a usage receipt. The escrow verifies against the transcript hash and moves toSETTLED, releasing payment to the provider on-chain.

Roadmap — going decentral

Today's centre of control → tomorrow's nothing.

🗂

Directory → DHT

Single REST directory becomes libp2p Kademlia + gossip. Listings are already content-addressed & signed — tamper-proof without a central server.

📡

Signalling → libp2p + relays

WS rooms move to P2P direct-connect with a small relay pool for NAT; the E2EE is transport-agnostic, so it just drops in.

🔗

Escrow → on-chain

Sim ledger becomes the real mesh-escrow Anchor program on Solana. The chainis the decentralised state machine.

🌐

Node becomes optional

With DHT + relays + on-chain escrow, theserver process shrinks to one seed node — the network runs without any single point.
